# 📦 Frontend Shared Packages

Các package chia sẻ giữa các frontend apps.

| Package | Mục đích |
|---------|----------|
| [ui-kit/](./ui-kit/) | Shared UI components (Button, Modal, Table, Form) |
| [api-client/](./api-client/) | Auto-generated API client từ OpenAPI + React Query hooks |
| [shared-types/](./shared-types/) | Shared TypeScript types |
| [eslint-config/](./eslint-config/) | Shared ESLint configuration |
| [tsconfig/](./tsconfig/) | Shared TypeScript configuration |
| [utils/](./utils/) | Shared utility functions (date, validation, format) |
