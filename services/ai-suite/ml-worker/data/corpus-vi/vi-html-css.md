# HTML và CSS cơ bản

HTML mô tả cấu trúc trang web, CSS mô tả cách trình bày.

## Thẻ ngữ nghĩa

Dùng header, nav, main, article, footer thay vì div cho mọi thứ. Trình đọc màn
hình dựa vào các thẻ này để giúp người khiếm thị điều hướng.

## Box model

Mỗi phần tử là một hộp gồm bốn lớp, từ trong ra ngoài: content, padding, border,
margin. Content là phần nội dung. Padding là khoảng đệm bên trong viền. Border là
đường viền. Margin là khoảng cách bên ngoài với phần tử khác.

Mặc định thuộc tính width chỉ tính phần content, nên thêm padding là phần tử
phình to ra. Đặt box-sizing bằng border-box thì width tính cả padding và border,
dễ tính toán hơn nhiều.

## Flexbox và Grid

Flexbox sắp xếp theo một chiều, dùng cho thanh điều hướng hoặc hàng nút bấm.
Grid sắp xếp theo hai chiều, dùng cho bố cục cả trang. Thường Grid dựng khung
tổng, Flexbox sắp xếp bên trong từng ô.
